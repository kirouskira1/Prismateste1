## PROJETO — JJCAC

JJCAC — Jiu-Jitsu para Todos | Projeto de Extensão UFPE — Em Produção

PWA de gestão de presenças para o projeto de extensão de Jiu-Jitsu da UFPE.

• Check-in via QR Code assinado (HMAC-SHA256) com validação de higiene e modo 100% offline (IndexedDB + sync automático).
• Painel administrativo com RBAC (aluno/monitor/admin), relatórios de frequência e notificações Web Push.

Tecnologias: Next.js 16, React 19, TypeScript, Supabase (RLS), Tailwind CSS v4, Docker.


## HABILIDADES TÉCNICAS

Front-end: React 19, Next.js 16 (App Router), TypeScript, Tailwind CSS, Framer Motion, PWA (Service Workers, IndexedDB).

Inteligência Artificial: Arquitetura de sistemas multi-agente, Model Context Protocol (MCP), RAG, Engenharia de Prompt, integração com LLMs (OpenAI, Gemini).

Banco de Dados: PostgreSQL (RLS, triggers, views, funções PL/pgSQL), Supabase (Auth, Storage), MySQL, modelagem de dados.

Segurança: Row Level Security (RLS), autenticação assinada com HMAC-SHA256, headers de segurança (CSP, HSTS), proteção contra brute-force, defesa contra Prompt Injection.

DevOps & Infra: Docker, Docker Compose, Vercel, AWS EC2, GitHub Actions.

Testes: Jest, Playwright, TestRail, testes unitários e E2E.
