## Phase 1: Foundation and Infrastructure

### For `taskId: infra_setup_build_time`

**Reasoning Prompt:**
> "Your mission is to configure Prisma's 'Factory Floor.'
> 1. Create a robust `docker-compose.yml` file.
> 2. Define the `embedding-service` using the `ollama/ollama` image and configure it to download and serve the `gemma:2b` model on startup. This is critical for Golden Rule #3 (Data Protection).
> 3. Define the `vector-db` service with the `pgvector/pgvector` image.
> 4. Define the `flowise` service and ensure it has network connectivity to `embedding-service` and `vector-db`.
> 5. **Self-Audit:** Verify no sensitive port is publicly exposed unnecessarily."

### For `taskId: setup_customer_rag`

**Reasoning Prompt:**
> "Now configure the 'Run-Time' infrastructure for the client.
> 1. Enable integration with **Google File Search API** (Gemini API).
> 2. Create a utility class `CustomerKnowledgeBase` in the backend (Supabase Edge Functions) that abstracts file upload and semantic queries.
> 3. This class will be used by all Policy Agents. It must receive a query and return the most relevant text excerpt from the client's rules."

## Phase 2: Business Agents (Policy Logic)

### For `taskId: create_policy_agent_service`

**Reasoning Prompt:**
> "You must create the base architecture for 'Policy Agents.'
> 1. Implement a generic `consultPolicyAgent()` function as a Server Action.
> 2. **Mandatory Logic:**
>    - Input: Decision context (e.g., order data).
>    - Action 1: Query `CustomerKnowledgeBase` with the context.
>    - Action 2: Send context + retrieved rules to the LLM (Gemini Flash) with a System Prompt instructing it to act as an impartial judge.
>    - Output: `ActionResponse<PolicyDecision>` with `{ decision, reason, citation, confidence }`.
> 3. **Self-Audit:** Ensure NO business rule is written in this base function's code."

### For `taskId: implement_specific_agents` (e.g., Financial)

**Reasoning Prompt:**
> "Implement the 'Financial Approval Agent' extending the base service.
> 1. Define the specific System Prompt: 'You are a financial auditor. Analyze the request against expense rules retrieved from the policy document.'
> 2. Do not write `if (value > 1000)`. The agent must read this from the document.
> 3. Mental test: If the client changes the rule from 1000 to 2000 in the document, does your code need to change? If 'no,' you passed."
